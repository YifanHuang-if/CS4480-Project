# Report build notes

## Compile

From this directory:

```powershell
latexmk -pdf -interaction=nonstopmode fx_open_project_report.tex
```

The PDF is `fx_open_project_report.pdf`. If that file is open in a PDF viewer, the compiler cannot overwrite it; close the viewer or use the latest `fx_open_project_report_final3.pdf` build. The `figures/` folder contains the ten images used in the report; the `.tex` file has no external dependencies beyond a standard TeX Live installation with `IEEEtran`.
