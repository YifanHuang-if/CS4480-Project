# Figure Generation

All figures are generated by Python code; none are hand-edited. The single entry point is:

```powershell
# from Project/
python data/regenerate_figures.py
```

The script:

1. recomputes the descriptive analyses from the cleaned data and redraws their figures;
2. redraws the benchmark figures from the **frozen** CSVs (`pool_reuse_*`, `scaling_benchmark_summary.csv`, `chunksize_sweep.csv`);
3. checks that all 22 expected PNG files exist and fails if one is missing.

It does **not** rerun the timing benchmarks, so the documented medians do not drift when only the figures are rebuilt.

## Re-measuring the benchmarks

If the timings need to be measured again, run the benchmark scripts explicitly, then rebuild the figures:

```powershell
python data/benchmark_pool_reuse.py
python data/plot_parallel_performance.py
python data/scaling_parallel_correlations.py
python data/benchmark_chunksize.py
python data/regenerate_figures.py
```

The medians may change with machine load and interpreter build; update the quoted numbers in the notes and report if they do.
