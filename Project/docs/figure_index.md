## Figure quality conventions

- Static `Agg` backend; no interactive windows.
- 200–300 dpi PNG output; titles, axis labels and units are included in each figure.
- Shared axes are used where comparison across panels is the point (daily changes, volatility, distributions).
- Colours are chosen for readability and are consistent across related figures.
- Every figure is regenerated from saved CSVs or raw inputs; no figure is hand-edited.
